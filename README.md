# Portfolio public — Richard Pearsall

Ce dépôt contient le site public de présentation du homelab : architecture, automatisation Infrastructure as Code et retour d'expérience sur une reprise après sinistre.

Le site est publié sur [richpea1982.github.io](https://richpea1982.github.io).

Les dépôts contenant le code d'infrastructure restent privés. Aucune adresse IP interne, aucun nom d'hôte interne et aucun secret n'est publié ici.
